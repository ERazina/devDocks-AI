# This is Dev docs AI project. It is a tool that helps developers to generate documentation for their code automatically. The project uses AI to analyze the code and generate relevant documentation in a structured format.

## Features

- Automatically generates documentation for code.
- Supports multiple programming languages.
- Provides a user-friendly interface for developers to interact with the tool.

### Installation

To install the Dev docs AI project, follow these steps:

1. Clone the repository: `git clone`
2. Navigate to the project directory: `cd dev-docs-ai`
3. Install the required dependencies: `pip install -r requirements.txt`

### Usage

To use the Dev docs AI project, follow these steps:

1. Run the tool: `python main.py`
2. Provide the path to the code you want to generate documentation for.
